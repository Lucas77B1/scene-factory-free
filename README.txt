SCENE FACTORY FREE
==================

The folder that turns Claude into your animation studio. You tell it the idea; it writes
the script, animates, adds captions and delivers the finished video.

This free version has 3 styles: Notebook, Neon and Voxel (light 3D).

You need: Claude on a paid plan (Pro is enough) and the Claude desktop app (claude.ai/download).

How to start (only once):

1. Put this folder somewhere easy to find, like Documents.
2. Open the Claude desktop app, go to the Code tab and choose this folder.
3. Paste this sentence and send it:

   Claude, set up the Scene Factory following the START-HERE.md file in this folder.

4. When it says it's done, ask for your video, your way.
   Example: "Make a 40-second video in the Neon style explaining why the sea is salty."

Finished videos go into the "finished-videos" folder.
